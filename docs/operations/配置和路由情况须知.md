# 配置和路由情况须知

## 1. 安装

建议使用 Python 3.11 或 3.12。在仓库根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[test]"
```

需要在同一环境运行 Docling 时：

```powershell
python -m pip install -e ".[docling,test]"
```

也可以让 Docling 使用独立虚拟环境，然后配置其命令路径。AnyDoc 不是 Python 包：

```powershell
npm.cmd install -g @firecrawl/anydoc@0.1.6
```

不同电脑的绝对路径不得写进代码或提交记录，应通过环境变量配置。

## 2. 环境变量

| 变量 | 默认值 | 说明 |
|---|---|---|
| `DOCUMENT_PARSER_ROUTE_PROFILE` | `local_first` | `local_first` 或 `quality_first` |
| `DOCUMENT_PARSER_ALLOW_CLOUD` | `true` | 为 `false` 时禁止 MinerU |
| `DOCUMENT_PARSER_LIBREOFFICE_AVAILABLE` | `false` | 仅在无头转换已验证后设为 true |
| `MINERU_API_TOKEN` | 空 | MinerU 精准 API Token，有效期需自行维护 |
| `MINERU_API_BASE_URL` | 官方 v4 地址 | MinerU 精准 API 根地址 |
| `DOCLING_EXECUTABLE` | PATH 检测 | Docling 命令绝对路径 |
| `ANYDOC_EXECUTABLE` | PATH 检测 | AnyDoc 命令绝对路径 |

PowerShell 临时配置示例：

```powershell
$env:MINERU_API_TOKEN = "<本次会话 Token>"
$env:DOCLING_EXECUTABLE = "C:\path\to\.venv\Scripts\docling.exe"
$env:ANYDOC_EXECUTABLE = "C:\Users\<user>\AppData\Roaming\npm\anydoc.cmd"
$env:DOCUMENT_PARSER_ROUTE_PROFILE = "local_first"
$env:DOCUMENT_PARSER_ALLOW_CLOUD = "true"
```

不要将真实 Token 写入 `.env.example`、测试、Markdown 或命令输出。命令行直接传 Token
可能被进程列表和终端历史记录保存，优先使用环境变量或 Python 构造参数。

## 3. Python 调用

```python
from document_parser import DocumentSignals, ParserCapability
from document_parser.routing import ModelRouter

# Standalone routing receives a caller-owned capability snapshot.  Production
# code normally lets DocumentParserGateway assemble this from its adapters.
capability_snapshot = [
    ParserCapability(
        parser_id="docling",
        provider="example",
        display_name="Docling",
        formats={".pdf"},
    )
]
router = ModelRouter.from_environment(capability_snapshot)
decision = router.route(
    DocumentSignals(
        extension=".pdf",
        size_bytes=1024,
        has_text_layer=True,
        language_hint="zh",
    ),
    profile="local_first",
    allow_cloud=True,
)
print(decision.model_dump_json(indent=2))
```

调用方也可以直接输入 Token，但它不会进入决策：

```python
router = ModelRouter.from_environment(
    capability_snapshot,
    mineru_api_token=token_from_secret_store,
)
```

通过现有 `ParseRequest.options` 切换任务策略：

```python
request = ParseRequest(
    filename="report.pdf",
    file_type="application/pdf",
    content=content,
    options={
        "route_profile": "quality_first",
        "allow_cloud": False,
        "libreoffice_available": True,
    },
)
decision = router.route_request(request)
```

## 4. CLI 调用

安装后可直接检查路由，不会执行解析：

```powershell
document-parser-route .\sample.pdf --profile local_first --allow-cloud
document-parser-route .\sample.pdf --no-allow-cloud
document-parser-route .\sample.doc --libreoffice-available
document-parser-route .\sample.pdf --parser-id docling
```

也可运行：

```powershell
python -m document_parser.routing .\sample.pdf --profile quality_first
```

## 5. 路由速查

| 格式 | local_first | quality_first | 禁止云端 |
|---|---|---|---|
| PDF | MinerU -> Docling | MinerU -> Docling | Docling |
| BMP/JPG/JPEG/PNG/WEBP | Docling | MinerU -> Docling | Docling |
| TIFF | Docling | 无损 PNG -> MinerU -> Docling | Docling |
| DOCX/PPTX/XLSX | Docling -> AnyDoc | Docling + AnyDoc 对比请求 | 不变 |
| DOC/PPT/XLS，有 LibreOffice | 转新版 -> Docling -> AnyDoc | 同左 | 不变 |
| DOC/PPT/XLS，无 LibreOffice | AnyDoc | AnyDoc | 不变 |
| HTML/AsciiDoc/EML/EPUB | Docling | Docling | 不变 |
| Markdown/TXT | 原文直通 -> Docling | 原文直通 -> Docling | 不变 |
| CSV | 保留原文，Docling -> AnyDoc | 保留原文并请求 AnyDoc 对比 | 不变 |

## 6. Adapter 必须遵守的配置

Docling：同时生成 Markdown 和 JSON，图片必须使用 referenced 模式，表格使用 accurate。
RapidOCR 是 Docling 内部配置，不注册为独立 parser ID。

MinerU：使用精准 API，不使用只返回 Markdown 的 Agent 轻量接口作为正式主链。Adapter
下载完整 Zip，安全保留结构 JSON 和图片；`extra_formats` 默认空，不额外生成
DOCX/HTML/LaTeX。

AnyDoc：主要用于旧 Office 和 Office 回退。它只生成 Markdown 时，原文件仍要作为原生
证据保存。

## 7. 统一结果目录

```text
document.md
images/
parsed_document.json
native/<实际 parser_id>/
routing_decision.json
quality/
task.json
```

Markdown 图片引用必须是相对 `images/` 的 POSIX 路径。`native/` 可以保留供应商原始
文件名，但 API 中只能暴露任务目录内安全相对路径。

## 8. 常见问题

- MinerU 显示不可用：检查 Token 是否配置、是否过期；免费 Token 当前规则为 90 天。
- Docling 显示不可用：设置 `DOCLING_EXECUTABLE`，不要写死本机部署路径。
- AnyDoc 显示不可用：确认 npm 全局命令在 PATH，或设置 `ANYDOC_EXECUTABLE`。
- PDF 在 local_first 仍走 MinerU：这是本次明确业务规则，不是实现错误。
- `allow_cloud=false` 后手动指定 MinerU：路由会拒绝，不会静默上传。
- 文件夹叫 `document_parser-main`：先执行 `pip install -e .`，不要依赖目录名导入。
