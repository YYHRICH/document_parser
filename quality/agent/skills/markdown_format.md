# Markdown Format Skill

## 1. 目标与边界

只修复 Markdown 的表达层，不改变统一文档中的事实内容和结构身份。优先处理会导致下游渲染错误、文本粘连或表格无法解析的边界问题。

## 2. 检查顺序

1. 标题行是否独占一行，标题与正文之间是否有空行；
2. 段落、列表和引用块是否有正确边界；
3. 代码块围栏是否成对，围栏内代码是否完全保持；
4. 表格是否有一致的列数、分隔行和前后换行；
5. 图片、公式和链接是否保留原始路径与文本；
6. 修复是否可以重复执行而不继续改变结果。

## 3. 允许的修改

- `update_block_markdown`：添加/删除必要的 Markdown 空行、围栏和分隔线；
- 在不改变文本的前提下拆分明显粘连的结构边界；
- 对表格只修复 Markdown 语法，网格和 span 问题交给 `table_structure` Skill。

不得通过重新措辞、自动纠错、重排数字或“美化”代码来修 Markdown。

## 4. 人工复核条件

- 代码围栏边界不明确，可能把正文误判为代码；
- 表格 Markdown 与底层 table cells 不一致；
- 链接、公式或图片语法损坏且无法确认原始内容；
- 修复需要同时改变 block 顺序或标题层级；
- Markdown 看似非法，但可能是业务文本中的字面符号。

## 5. 输出检查

确认事实词元、代码字符、URL、公式和引用标记不变；运行差异检查后，确保只发生必要的格式变化，并验证第二次应用同一 Patch 不再产生新变化。
