# shared-dev-v1

公开合成共享开发数据集，供路由、Adapter、ParsedDocument 和质量层共同联调。

- Development：12 个唯一文件，覆盖企业知识库、事故复盘、工单扫描件、采购表格、跨页/合并单元格表格、技术报告引用、报销票据、使用量仪表盘、长知识库页面、文学计算论文和 DOCX 变更申请单。
- Smoke：sdp-001、sdp-004、sdp-007、sdp-008
- Golden：sdp-004、sdp-005、sdp-006、sdp-007
- 所有正文均为项目生成的合成内容，无客户数据和个人信息；sdp-011 仅引用公开 arXiv 元数据，正文为解析测试重构样例

`manifest.jsonl` 是文件身份、类别、子集和 SHA-256 的唯一事实源。最终输入文件在 `files/`；PDF/图片样例的可复现源在 `sources/tex/`，DOCX 回归样例由确定性的 Open XML 构建。

质量层只读取当前 `ParsedDocument`；Golden 文件描述应产生、延续或安全拒绝的关系，不绑定解析器私有结构。对于扫描件、票据和截图，OCR 标注记录应提取的业务字段与应安全降级的场景；文学论文样例用于验证章节、摘要和参考文献结构。
